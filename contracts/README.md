# Pocket Drop contracts

Solidity 0.8.28 (pragma ^0.8.24), Foundry, QoreChain **Diana testnet only** (EVM chain id 9800). No owner, no admin, no upgrade.

- `src/PocketDrop.sol`, `src/PqcLib.sol`, `src/interfaces/IPocketDrop.sol`
- Spec: `../SPEC.md` (sections 2, 3, 4, 6). Security notes: `SECURITY.md`. Coverage: `COVERAGE.md`. Live results: `LIVE_RESULTS.md`.

## Build and test
```
forge build
forge test                              # default profile (fuzz 1,000 runs)
FOUNDRY_PROFILE=ci forge test           # fuzz 10,000 runs, invariants 256 runs x depth 50
forge coverage --report summary --no-match-coverage "(test|script|lib)/"
```
Tests: unit (`test/PocketDrop.t.sol`), fuzz (`test/PocketDrop.fuzz.t.sol`, `test/PqcLib.t.sol`), invariants (`test/PocketDrop.invariant.t.sol`).

The precompile mocks are signature-real: `test/fixtures/pqc.json` holds real ML-DSA-87 keys and signatures generated by
`npm run fixtures` (`@qorechain/pqc`), and the mock verifier accepts only exactly those (pk, sig, msg) triples.
`npm run verify-fixtures` re-verifies every fixture against the real verifier and checks that mutated inputs fail.
Foundry cannot fork native precompiles, so the live suite below replaces fork tests.

## Deploy and live suite (testnet, needs secrets in `D:\route\QORE\.secrets\`)
```
npm install
node script/setup-deployer.mjs 15   # fresh deployer, funded from the main test wallet, PQ key + EVM window
node script/deploy.mjs              # deploys main + lab instances, writes deployments/diana.json
node script/deploy.mjs --check      # compares on-chain runtime code with the local build
node test/live/run.mjs              # every success path + the 6 lab attacks as real txs
```
`lab` is the same bytecode with BIND_TIMEOUT 60 s so rebind-after-timeout can be shown live.
